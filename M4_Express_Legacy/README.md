# M4 Express Legacy examples

These examples were written for the **Adafruit Feather M4 Express with the Prop-Maker FeatherWing**, which is no longer the course hardware.

They are kept so existing tutorials and links keep working. They will not run unchanged on the current board, the **Adafruit Feather RP2040 Prop-Maker** (differences include no DAC audio output, different pin names, and no 3W LED outputs).

For the current examples, see [Code](../Code).
